# Selected source support contracts

Generated by `tools/generate-support-matrix.py` from `--capabilities`.
Each row describes an operation compiled into the binary. Platform validation
requires separate evidence about the target, source, layout and test run.

## Standalone probe contracts

The command syntax and scope come from the executable. Contracts can share
one invocation when it collects more than one observation.

| Contract | Invocation | Availability scope | Observation |
| --- | --- | --- | --- |
| `owned_read` | `--capabilities --probe` | `owned_control_range_only` | Reads and compares a known 32-byte range in the collector process. |
| `native_connection` | `--capabilities --probe` | `connection_contract_only` | Checks the existing device connection, ABI and session. Native operations require separate evidence. |
| `saved_etl_family` | `--capabilities --probe-etl <local.etl> --sha256 <digest>` | `supplied_etl_record_family` | Checks the decoded layout and records of one event family in a pinned ETL. |
| `saved_dump_range` | `--capabilities --probe-dump <local.dmp> --header-sha256 <digest> [--range <hex-va> <1..4096>] [--expect-sha256 <digest>]` | `supplied_dump_virtual_range` | Reads one virtual range in a header-pinned full dump. The default module list head also checks reciprocal links. |
