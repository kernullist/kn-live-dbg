# Selected source support contracts

Generated by `tools/generate-support-matrix.py` from `--capabilities`.
This is a selected compiled inventory, not a validated platform matrix.
Runtime observations come from `--capabilities --probe` and remain private.
The probe opens only its own process and an existing native device; it does
not start a service or load a driver. Connection, sample, layout, semantics
and environment validation have separate states. A successful owned read
qualifies that control range only. Native connection checks stay partial.

Address shape does not establish mapped memory, effective permissions,
decoder coverage or real LA57 compatibility. `legacy_la48` is the explicit
compatibility assumption for recorded inputs that declare it. Current
native paths use the source descriptor where identified below; remaining
collectors require their own admission/layout/decoder validation. WOW64
pointer slots, VTL1, other CPU architectures and hardware execution
backends are not implied by an x64 address width.
